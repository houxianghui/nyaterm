# GPUI macOS 交互迁移设计

日期：2026-11-03  
状态：已获对话内设计确认，等待书面 spec 复核

## 1. 目标与成功标准

在保留 NyaTerm 现有终端、连接、认证、同步、草稿和窗口行为的前提下，将当前偏 IDE 的 GPUI 交互逐步迁移为 macOS 的 source list、toolbar、Inspector、segmented control、grouped list、disclosure 和 sheet 模型。

成功标准：

- 短互斥选项不再依赖下拉隐藏选择，常用设置可在一次点击内完成。
- 主窗口提供清晰的 source list 默认导航和单 Inspector，不强迫用户理解四区域 Activity Bar。
- 各业务页面形成一致的列表—详情—操作路径，危险操作与普通操作分离。
- 键盘焦点、菜单状态、滚动、窗口缩放、亮暗主题和窄窗口行为与鼠标路径一致可用。
- 每阶段可独立编译、验收和提交，不把未完成页面宣称为全部完成。

## 2. 约束与非目标

- 保留设置 draft、保存、取消、校验和未保存关闭确认语义。
- 保留 Windows 窗口控制位置和现有平台快捷键，不机械复制 macOS 窗口按钮布局。
- 不改变 SSH、终端、SFTP、RDP、VNC、认证、加密、同步和持久化数据格式。
- 不删除现有 Activity Bar 布局配置；简洁模式与兼容布局并存。
- 长列表、可搜索选项继续使用下拉，不把所有菜单替换为 segmented control。
- 不通过移除确认、隐藏危险后果或减少凭据保护来追求视觉简洁。

## 3. 实施方案

采用“共享交互原语 + 分阶段页面迁移”。不使用纯样式覆盖，也不整体重写应用。

### 3.1 共享交互原语

在 `nyaterm-ui` 增加或完善：

1. `NyaSegmentedControl`
   - 2～4 个短互斥选项。
   - 单一选中值、点击回调、禁用状态、可访问名称。
   - 左右方向键移动选择，Home/End 到首尾，Enter/Space 激活。
   - 使用现有 accent、圆角和字号体系，不新增平行主题色。
2. 焦点与菜单规范
   - 所有键盘可操作控件有明确焦点环。
   - hover-only 的行操作在 hover、选中或焦点路径上可见。
   - 菜单当前状态用勾选表示，不仅使用灰字禁用。
3. Grouped list 与 disclosure
   - 用缩进、字重和间距表达层级，移除普通嵌套设置的装饰竖线。
   - 高级配置默认折叠，展开状态不打断表单输入和滚动位置。
4. 统一反馈
   - 异步按钮提供进行中状态并防止重复提交。
   - 行内错误优先于弹窗；危险操作仍保留现有确认。

这些原语只依赖 GPUI 与 `nyaterm-ui` 的现有抽象，desktop 不直接依赖 gpui-kit。

### 3.2 设置页迁移

共享 `SettingsPanel` 继续使用同一份状态和 draft，仅替换展示与输入控件。

| 页面 | 展示与交互变化 |
| --- | --- |
| 常规 | 日志级别改 segmented；嵌套启动项去竖线；诊断操作归入一致行级布局 |
| 外观 | 背景图缩略预览与拖放；透明度滑杆加数值；主题设计器保持独立工作流 |
| 交互 | 短行为选项改 segmented；数值项 stepper；依赖设置缩进展示 |
| 快捷键 | 原位录制、行内冲突、逐行重置、仅自定义筛选 |
| 终端常规 | Keep Alive segmented；数值 stepper；X11 等高级字段 disclosure |
| 远程监控 | 采样控制集中，按当前设备或连接限定配置范围 |
| 搜索 | 行为与引擎配置分组，引擎列表加详情，测试反馈行内化 |
| 翻译 | 服务、凭据和高级参数分层，测试翻译提供明确异步状态 |
| AI 常规 | 基础与高级行为分组，危险权限保留说明与确认 |
| AI 模型 | 模型列表加详情，新增/编辑使用 sheet，测试和拉取显示进度 |
| AI 规则 | 规则启用、排序、详情编辑与优先级反馈 |
| AI Agents | 状态列表、运行详情、日志 disclosure，启动/停止防重复 |
| 传输 | 路径选择、并发 stepper，确认仅用于覆盖和删除等危险行为 |
| 安全 | 主密码、锁定和凭据保护分组，危险重置独立放置 |
| 同步与备份 | 账户状态、立即同步进度、冲突选择，解除关联和清远端独立分区 |

### 3.3 主导航与 Inspector

新增简洁展示模式，不迁移或删除已有持久化配置：

- 左侧 source list 使用图标加文字和 Finder 式选中块。
- 右侧 Connections、AI、Sessions、History、Monitor、Processes、Docker 等共享单 Inspector，通过 segmented 或 source list 切换。
- 现有四区域 Activity Bar 作为兼容布局保留，用户可切回。
- 面板打开、关闭、恢复和持久化继续由现有 shell 状态负责，不复制第二套导航状态。

### 3.4 业务页面迁移

- Workspace：弱化分割条和低频工具，保留终端焦点、查找、选择和标签行为。
- Connections：单击选择、双击连接，source list 加详情，单一主连接操作。
- Transfers：增加类型选择、Quick Look、返回/前进与一致的传输反馈；复用当前文件系统操作，不另建传输通道。
- Tunnels：列表选择后显示详情和日志，启动/停止为主操作。
- Notes：可搜索列表、选中即编辑、行内重命名。
- Security：Keychain 式分类、搜索和详情，秘密默认隐藏。
- Sync History：状态 segmented filter、相对时间、选中展开详情。
- Plugins：列表内启用、版本和来源，详情 sheet，安装和删除分级。
- AI：聊天主体优先，composer 固定底部，模型选择靠近 composer，流式状态切换 Send/Stop。
- Sessions、History、Recording：统一列表—预览—操作。
- Resource/GPU/NPU：资源 segmented、减少边框和网格，集中采样控制。
- Processes/Docker：选中行显示详情，危险操作独立，避免行内主按钮堆叠。

## 4. 状态与数据流

- 新控件只发射选择或编辑事件，真实值继续写回现有设置 draft 或页面 Entity。
- 不新增与现有设置平行的持久化字段；简洁导航若需持久化，复用现有 UI 配置扩展机制并提供旧配置默认值。
- Quick Look 只读展示当前选中条目，通过已有本地/远程文件读取路径获取元数据和受控预览，不执行文件内容。
- 异步测试、同步、模型拉取和启停操作继续使用现有任务所有权、取消和错误通道。
- 危险操作、凭据 reveal、同步冲突和远端删除沿用现有确认与审计路径。

## 5. 错误处理与可访问性

- 输入校验在提交前显示于对应行，失败不清空 draft。
- 异步操作失败恢复可操作状态并保留上下文，不静默忽略。
- 焦点不能被 hover、面板切换或异步刷新无故夺走。
- 列表删除、过滤和排序后维持合理选中项与滚动位置。
- 图标按钮具有可访问名称和 tooltip；颜色不是唯一状态表达方式。
- 窄窗口优先换行或折叠详情，不产生不可达操作。

## 6. 阶段与提交边界

1. 共享 segmented、焦点、菜单状态和 grouped list。
2. 常规、交互、外观、快捷键设置页。
3. 其余设置页。
4. 简洁 source list 与单 Inspector。
5. Transfers、Connections、Security、History、Plugins。
6. AI、Resource、Processes、Docker 和剩余页面。

每阶段执行格式检查、`cargo check`、相关测试、release 和真实应用验收后单独提交。只有当前阶段完成才进入下一阶段。

## 7. 验证要求

- 新共享控件：选项、键盘、禁用、事件和可访问名称测试。
- 设置迁移：沿用现有 draft、校验、取消和持久化测试。
- 页面交互：选择、详情、危险操作、异步状态和滚动恢复测试。
- 真实应用：亮暗主题、窄窗口、键盘、鼠标、窗口缩放、独立设置窗口无边框和八方向 resize。
- 本机 desktop 测试若仍被执行策略阻止，明确记录并由 CI 补跑，不声称本地测试通过。

## 8. 文档同步

每阶段更新 `docs/macos-visual-migration.md` 的完成状态。圆角、透明背景或 DWM 相关改动继续遵循 `docs/gpui-rounded-windows.md`，不得重新引入已否决的窗口边框方案。
